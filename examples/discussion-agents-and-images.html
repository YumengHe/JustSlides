1  Patchify

Cut the image into small squares, 14 to 16 px each

2  Encode

A vision transformer turns each patch into a vector

3  Project

A small network maps those vectors into the LLM’s token space

4  Interleave

Visual tokens sit next to text tokens in one sequence

An image is a long token sequence

Claude: about width × height / 750 tokens

1000 × 1000 px ≈ 1,300 tokens, about a page of text

More pixels, more tokens, more cost
